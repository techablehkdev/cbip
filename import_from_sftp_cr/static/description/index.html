FTP/SFTP File Import (CSV/EXCEL)

This module allows you to import file hosted on FTP/SFTP server and move imported file to another folder based on the configuration for the folders.
1. Authentication by Password/Passphrase
2. User will be able to import any object data using csv/excel File
3. Dynamic Model Configuration like Lead/Opportunity, Contacts, Invoice etc.
4. User will be able to download Sample CSV file after Field Mapping
